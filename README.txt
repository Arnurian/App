HSK 5: сборка Android-приложения (APK)

Что внутри: сам файл приложения (www/index.html), настройки Capacitor и готовая автоматическая сборка на GitHub. Тебе не нужны Android Studio и мощный компьютер.

Шаги (можно с телефона через браузер, но удобнее с компьютера):
1. Зарегистрируйся на github.com (бесплатно) и создай новый репозиторий (New repository), любое имя, без README.
2. Загрузи в него ВСЕ файлы из этого архива, сохранив папки: www/, .github/workflows/, package.json, capacitor.config.json, .gitignore (кнопка «Add file» → «Upload files»; папку .github с точкой в начале на телефоне загрузить сложнее, лучше с компьютера).
3. Открой вкладку Actions → «Build APK» → «Run workflow». Сборка идёт 5–10 минут.
4. Когда появится зелёная галочка, открой запуск и внизу в блоке Artifacts скачай hsk5-apk (это zip с файлом app-debug.apk).
5. Скопируй app-debug.apk на телефон и открой его. Android попросит разрешить установку из этого источника (разреши в настройках).

Что получится: приложение работает офлайн, прогресс хранится на телефоне. Это отладочная сборка (debug), не для магазина приложений.

Если шаг сборки упадёт, открой лог запуска (красный крестик) и пришли мне последние строки с ошибкой.
Обновление приложения: заменить www/index.html новым файлом и снова запустить сборку. Прогресс при переустановке поверх сохраняется, если не удалять приложение.
